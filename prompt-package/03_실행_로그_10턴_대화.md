# 실행 로그: 10턴 이상 대화 및 문맥 유지 검증

## 1. 시나리오 설명

선택 과업은 `회의록 요약 및 Action Items 추출`이다. 사용자는 회의 원문을 제공하고, 중간에 톤과 출력 대상을 변경하며, 뒤늦게 정책성 정보를 추가한다. 이후 회의보고 메일의 대상자를 실무팀에서 임원진으로 바꾸는 수정 요청도 한다. AI는 이전 조건을 유지하면서 변경된 조건만 반영해야 한다.

문맥 유지 Pass 기준은 다음과 같다.

1. 역할명 표기, 원문 외 정보 생성 금지, 확인 필요 분리 규칙을 끝까지 유지한다.
2. 조건 변경이 들어오면 변경된 톤이나 대상만 바꾸고 나머지 규칙은 유지한다.
3. 정책/수치/일정은 근거가 없으면 확인 필요로 표시한다.
